# Powergas Customer App (React Native)

Customer-facing app: register/login, OTP, ordering (exchange/new/refill/emergency),
live delivery tracking via Socket.IO, order history, notifications, ratings.

## Run
```bash
npm install
npm run android   # or: npm run ios
```
Backend must be running. Android emulator reaches the host API at `10.0.2.2:3000`.
